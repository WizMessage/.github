# Security

Please report a security problem in WizMessage to info@bethtechnologies.com. Do not open a public issue, and do not include a key, a password or a customer's phone number.

WizMessage keys start with `pk_live_` and are secret, like the key secrets (`sk_live_`) and webhook secrets (`whsec_`). If one may have been seen by somebody else, open WizMessage, switch the key off at once and make a new one.
