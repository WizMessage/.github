# WizMessage

WizMessage is a team inbox and messaging platform for WhatsApp Business. A company connects its own number through Meta's onboarding, answers customers together, sends approved templates and automates replies with chatbots. It runs on Meta's WhatsApp Business Platform (Cloud API).

## For developers

- **[WizMessage MCP server](https://github.com/WizMessage/wizmessage-mcp)**: AI agents read conversations, reply and send approved templates. Setup for each tool: [wizmessage.com/pages/mcp](https://wizmessage.com/pages/mcp).
- **[API guide](https://wizmessage.com/user-manual/connecting-your-software-to-whatsapp)**: keys, sending messages, receiving replies by webhook.
- **[Summary for AI assistants](https://wizmessage.com/llms.txt)**
